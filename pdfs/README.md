# PDFs de Kind Studios

Copia aquí los PDFs de la aplicación y deja los nombres indicados en `../config.js`.

Para usar otro nombre, cambia sólo el valor `pdf` correspondiente en `config.js`. Por ejemplo:

```js
{ title: "Póker Night Live", pdf: "pdfs/mi-archivo.pdf" }
```

La aplicación muestra los PDFs dentro de su propio contenedor.
